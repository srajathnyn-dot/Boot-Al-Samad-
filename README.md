# بوت كلية الصماد للقرآن الكريم

## نظرة عامة على المشروع
- **الاسم**: webapp (بوت كلية الصماد للقرآن الكريم)
- **الهدف**: منظومة تلجرام متكاملة لخدمة طلاب كلية الصماد للقرآن الكريم تتضمّن إدارة الطلاب، المجموعات، الردود التلقائية، المناهج الدراسية، والاستعلام عن الدرجات.
- **الواجهة الإدارية**: لوحة تحكم ويب قابلة للتثبيت كتطبيق PWA على الهواتف والكمبيوتر.

## ✨ الميزات الرئيسية

### 🆕 تحديثات V4 (الإصدار الأحدث — 2026)
1. **ربط أزرار المناهج بالمستويات والفصول**: عند ضغط زر مستوى في قائمة المناهج، يتم الآن عرض اختيار الفصل بدلاً من تجمّد البوت. أُضيفت آليات حماية:
   - بدائل تلقائية إذا كانت قاعدة بيانات المستويات فارغة (تستخرج المستويات من جدول المناهج، ثم تستخدم المستويات الافتراضية 1–4).
   - تشفير صحيح لأسماء المستويات/الفصول في `callback_data` لمنع كسر الأزرار.
   - رسائل خطأ ودّية مع أزرار "رجوع" و"القائمة الرئيسية" عند أي فشل.
2. **استعلام الدرجات أصبح يستجيب**: عند إرسال الرقم الأكاديمي:
   - تطبيع تلقائي للأرقام العربية والفارسية إلى إنجليزية.
   - بحث بصيغ متعدّدة (مع/بدون أصفار بادئة).
   - تخطي اختيار الفصول إذا كان فصل واحد فقط → عرض النتائج مباشرة.
   - إدارة سلسة للجلسة في `grades_sessions` مع رسائل خطأ واضحة.
3. **رفع ملفات الدرجات الكبيرة (ملايين السجلات)**:
   - رفع متوازٍ (chunk concurrency = 2) مع حد أقصى للضغط على D1.
   - إعادة المحاولة الذكية مع backoff تصاعدي (1.5s → 15s، حتى 5 محاولات).
   - حجم batch SQL تم تقليله من 50 إلى 25 جملة لتفادي حدود D1.
   - حجم الـ chunk الافتراضي في الواجهة: 200 سجل (بدلاً من 500).
4. **أمان المجموعات**:
   - **إخراج البوت من أي مجموعة**: زر مخصّص في لوحة "المجموعات" يستدعي `leaveChat` فوراً.
   - **منع الإضافات غير المصرّح بها**: عند إضافة البوت لأي مجموعة، يتم التحقق:
     - هل من أضافه مالك أو مشرف لديه صلاحية `can_manage_groups`؟
     - أو هل المجموعة في قائمة `allowed_groups` (whitelist)؟
   - عند الفشل، يغادر البوت تلقائياً بعد إرسال رسالة شرح، ويُبلَّغ المالك.
   - إعدادات قابلة للتفعيل/التعطيل من اللوحة: `restrict_bot_to_admins_only`, `auto_leave_unauthorized_groups`.
5. **أيقونات PWA كاملة**: تصميم جديد بمئذنتين وقبة بألوان زمردية:
   - أحجام `72/96/144/192/512` للأيقونات العادية.
   - نسخة maskable خاصة (`192/512`) للأندرويد بدون قطع الزوايا.
   - أيقونات favicon (16/32/64) و apple-touch-icon (180).
   - SVG أصلي يخدم كأيقونة عالية الدقة.
   - manifest.json محدّث، sw.js v3 يحتوي قائمة كاملة في APP_SHELL.
6. **محرّر النصوص محدَّث**: أُضيفت أكثر من **30 رسالة جديدة** لمحرّر النصوص (إجمالي 102 نص قابل للتحرير) تشمل:
   - أوامر `/cancel`, `/help`, `/id`, `/me`, `/admin`, `/panel`.
   - بطاقة الإحصائيات `/stats`.
   - رسائل ردود المشرفين على الطلبات.
   - رسائل أخطاء تحميل المناهج.
   - رسائل أمان المجموعات.
   - أزرار عامة (رجوع، إلغاء، القائمة الرئيسية).
   - رسائل أخطاء جلسات الدرجات.
   - تم تنظيف الإيموجيز الزائدة لجعل الرسائل أنظف وأسهل قراءة.

### 🔧 إصلاحات وتحديثات هذا الإصدار (V3)
1. **🛡️ إصلاح حذف روابط أوامر البوت**: لم تعد أوامر البوت (`/menu@Samad0_bot`, `/start`, …) تُحذف عن طريق فلتر الروابط؛ تمّ إنشاء **قائمة بيضاء** ديناميكية تستثني الأوامر المخصّصة والافتراضية للبوت من فلتر حذف الروابط في المجموعات.
2. **📅 صفحة اختيار الفصل في الدرجات**: لم تعد خطوة اختيار الفصل تُتجاوز عندما يوجد فصل واحد فقط؛ صار الطالب يرى دائماً قائمة الفصول مع زر **"📊 عرض كل الفصول"** و **"☑️ اختيار كل الفصول"**.
3. **🎓 منهج لكل فصل**: الآن لكل مستوى دراسي عدة فصول، يختار الطالب المستوى ثم الفصل ثم يرى مواد ذلك الفصل. يمكن للمشرف من اللوحة:
   - إضافة مستويات دراسية لا نهائية.
   - إضافة فصول دراسية لا نهائية لكل مستوى.
   - تعيين المنهج (المواد) لكل تركيبة (مستوى + فصل) مع دعم العام الدراسي اختيارياً.
4. **🔔 إشعارات Web Push + PWA**:
   - إشعارات فورية لجميع المشرفين على الويب (تعمل حتى لو كان المتصفح مغلقاً).
   - **نافذة "إدارة الأجهزة"**: المشرف يرى أجهزته المسجَّلة، يفعّل/يعطّل كلّ جهاز على حدة، أو يحذفه.
   - **تثبيت اللوحة كتطبيق (PWA)**: زر "تثبيت كتطبيق" + manifest + service worker → يمكن لكل مشرف تثبيت اللوحة كتطبيق مستقل على هاتفه أو حاسوبه.
5. **👥 المشرفون المتعدّدون كمستلمين للإشعارات**:
   - جميع المشرفين (لا المالك فقط) يستلمون الآن: طلبات الانضمام، الأسئلة، الطلبات، إجراءات الإشراف، الإذاعات.
   - **مصفوفة توجيه شخصية لكل مشرف × نوع حدث**: تيليجرام / إشعار ويب / كلاهما / إيقاف.
   - عند ردّ أيّ مشرف، يُبلَّغ الآخرون فوراً برسالة: «المشرف X تكفّل بهذا الطلب — لا حاجة للردّ».
6. **📜 سجل الإشعارات**: لوحة تعرض جميع الأحداث، نوعها، عدد المُرسَل عبر تيليجرام/الويب، وقت الإرسال.

### 🆕 نقاط API الجديدة V4 (تحت `/admin/api`)
- `POST /groups/:id/leave` — يستدعي `leaveChat` لإخراج البوت من مجموعة محدّدة.
- `GET /allowed-groups` — قائمة المجموعات المسموح بها.
- `POST /allowed-groups` — إضافة مجموعة لقائمة الأمان (whitelist).
- `DELETE /allowed-groups/:id` — حذف مجموعة من قائمة الأمان.
- `GET /groups/security/settings` — قراءة إعدادات أمان المجموعات.
- `POST /groups/security/settings` — تحديث إعدادات أمان المجموعات.

### نقاط API السابقة (تحت `/admin/api`)
- **PWA / Push**:
  - `GET /push/public-key` — مفتاح VAPID العام
  - `POST /push/init` — توليد مفاتيح VAPID (مرة واحدة)
  - `POST /push/subscribe` — تسجيل جهاز جديد
  - `POST /push/unsubscribe` — إلغاء تسجيل
  - `GET /push/devices` — أجهزة المشرف الحالي
  - `GET /push/all-devices` — جميع أجهزة المشرفين (للمالك)
  - `POST /push/devices/:id` — تفعيل/تعطيل جهاز
  - `DELETE /push/devices/:id` — حذف جهاز
  - `POST /push/test` — إرسال إشعار تجريبي
- **توجيه المشرفين**:
  - `GET /admin-routing` — مصفوفة التوجيه
  - `POST /admin-routing` — حفظ قناة لمشرف/حدث
  - `DELETE /admin-routing/:tid/:event_type` — حذف
- **الأكاديميات**:
  - `GET|POST /academic/levels`, `POST|DELETE /academic/levels/:id`
  - `GET|POST /academic/semesters`, `POST|DELETE /academic/semesters/:id`
- **متفرّقات**:
  - `GET /notifications/log` — آخر الإشعارات
  - `GET /bot-commands` — قائمة الأوامر البيضاء
  - `POST /account/telegram-link` — ربط حساب اللوحة بـ telegram_id

## 🗂️ بنية البيانات (المعدّلة)

### جداول جديدة
- `academic_levels` (id, name, display_order, is_active)
- `academic_semesters` (id, name, short_name, level_name, display_order, is_active)
- `push_devices` (id, panel_user_id, endpoint, p256dh, auth, label, ua, enabled)
- `admin_routing` (id, telegram_user_id, event_type, channel, is_active)
- `notifications_log` (id, event_type, title, body, telegram_sent, webpush_sent, …)
- `bot_command_whitelist` (id, command, description, is_active)

### تعديلات على جداول قائمة
- `curriculums`: أُضيف عمود `semester` (الفصل) و `academic_year` (العام الدراسي).
- `settings`: حقول جديدة لـ VAPID (`vapid_public_key`, `vapid_private_key`, `vapid_subject`).
- `bot_admins`: عمود جديد `can_manage_groups` (تصريح المشرف لإدارة إضافة البوت للمجموعات).
- `groups`: عمودان جديدان `added_by_user_id`, `added_by_username` (تتبّع من أضاف البوت).

### جداول V4 الجديدة
- `allowed_groups` (id, chat_id, title, note, created_by, created_at): قائمة بيضاء للمجموعات المسموح للبوت بالانضمام إليها.
- إعدادات جديدة في `settings`:
  - `restrict_bot_to_admins_only=1`: تقييد إضافة البوت للمشرفين فقط.
  - `auto_leave_unauthorized_groups=1`: مغادرة تلقائية للمجموعات غير المصرّح بها.
- `bot_texts`: أكثر من 30 مفتاح جديد ضمن categories: `commands`, `requests`, `curriculum`, `groups`, `grades`, `admin`, `buttons`, `welcome`.

تمّ تحويل كل أزرار البوت العادية إلى Reply Keyboard دائم. الأوامر التالية تبقى متاحة كأوامر `/` لأنها للمالك/المشرفين فقط ولن تُحذف:

| الأمر | الوصف |
|---|---|
| `/start` | بداية المحادثة مع البوت |
| `/menu` | عرض القائمة الرئيسية |
| `/help` | المساعدة |
| `/id` | معرفة معرّف المستخدم |
| `/me` | معلومات حسابي |
| `/cancel` | إلغاء العملية الحالية |
| `/admin` | فتح لوحة المشرف داخل تيليجرام |

> 💡 يمكن إضافة المزيد من الأوامر إلى القائمة البيضاء من قاعدة البيانات (جدول `bot_command_whitelist`) أو إنشاؤها عبر تبويب "الأوامر المخصّصة"؛ ستُستثنى تلقائياً من حذف الروابط.

## 📲 دليل سريع للمستخدم (المشرف)

1. **سجّل الدخول** على `https://your-domain.pages.dev/admin/login`.
2. اذهب إلى **🔔 الإشعارات والأجهزة**:
   - إن لم تكن VAPID مهيّأة، اضغط **"تهيئة VAPID"** (مرّة واحدة).
   - اضغط **"تفعيل الإشعارات على هذا الجهاز"** → يطلب المتصفح إذناً → اقبل.
   - اضغط **"تثبيت كتطبيق"** لتثبيت اللوحة على شاشة الهاتف/سطح المكتب.
3. اذهب إلى **📡 توجيه الإشعارات**: اختر لكل نوع حدث كيف ترغب باستلامه (تيليجرام / ويب / كلاهما / إيقاف).
4. اذهب إلى **🎓 المستويات والفصول**: أضِف ما تشاء من مستويات وفصول.
5. اذهب إلى **المناهج الدراسية**: عيِّن المواد لكل تركيبة (مستوى + فصل + عام دراسي اختياري).
6. **📜 سجل الإشعارات**: راجع كل ما أُرسِل من إشعارات عبر النظام.

## ☁️ النشر على Cloudflare Pages

```bash
npx wrangler d1 migrations apply webapp-production   # على الإنتاج
npm run build
npx wrangler pages deploy dist --project-name webapp
```

## 🧱 المنصّة والتقنيات
- **Backend**: Hono (TypeScript) على Cloudflare Workers/Pages
- **Database**: Cloudflare D1 (SQLite)
- **Frontend**: HTML + TailwindCSS (CDN) + JavaScript (Vanilla) + FontAwesome
- **PWA**: Service Worker + Web App Manifest + Web Push (VAPID + AES-128-GCM)
- **Auth**: Cookie sessions، PBKDF2 بكلمات مرور مشفّرة
